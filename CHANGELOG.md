# Changelog

## 0.9.4

- Bug-report logs now tell the whole story: picks, campfires, biomes, knockouts and revives always leave a line in the log, so an F9 report without a comment is still diagnosable. These are a handful of lines per run - no spam.
- Controller focus problems log a warning instead of hiding.
- Bug reports record the game version cleanly (PEAK's own version string carries a launch-arg fragment; it is trimmed now).

## 0.9.3

First Thunderstore release.

- **F9 bug reports**: press F9 in game, tick what went wrong, add a comment, and send. The attached log is scrubbed first - player names, user folders, Steam ids, lobby ids, IPs and e-mails never leave your machine.
- **Deck screen (J)** now shows every player's cards with an ALL CARDS ADDED UP panel per deck; the HUD corner is a one-line hint instead of stacked totals.
- **Branding**: the campfire logo is on every card back, and each pick screen carries the Campfire Cards wordmark.
- Jump cards ease gravity during the jump arc, so the printed percent shows up in real apex and hang time instead of being eaten by the game's body drag.

## 0.9.2

- Jump-feel fix behind the scenes (folded into 0.9.3 above).

## 0.9.1

- Knockouts honor bonus stamina, The Eternal Campfire revives on death, and reach pulls no longer drop climbers.

## 0.9.0

- Public beta: 64 cards, team decks, scout abilities, and the campfire pick flow.
